# Floating Label Form

A clean and responsive floating label form built with Tailwind CSS.

## Features

- Floating label inputs
- Form validation and error states
- Focus and placeholder states
- Required fields
- Interactive submit button
- Peer-based state styling
- Responsive layout
- Font Awesome icons
- Reusable custom styles with `@apply`
- Custom theme colors with `@theme`
- Built with utility-first Tailwind CSS

## Technologies

- HTML5
- Tailwind CSS v4
- Font Awesome
