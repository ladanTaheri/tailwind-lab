# Online Course Platform Landing Page

A modern and responsive landing page redesign inspired by the **TopLearn** website, built as part of the **Tailwind Lab** collection.

## Features

* Responsive navigation bar
* Hero section
* Course categories section
* Featured courses section
* Latest articles section
* Call-to-action sections
* Footer
* Mobile-first responsive design
* Responsive layouts using Tailwind CSS
* Modern UI with reusable utility classes

## Technologies

* HTML5
* Tailwind CSS
* Responsive Design
* Flexbox
* CSS Grid
* Font Awesome

## Learning Objectives

* Practice building modern landing pages
* Improve responsive design skills
* Build layouts using Tailwind CSS
* Practice Flexbox and CSS Grid
* Organize reusable utility classes
* Recreate and redesign an existing website interface
* Improve visual hierarchy and UI structure

## Reference

This project is a redesign and frontend implementation of the **TopLearn** website.

https://toplearn.com/
